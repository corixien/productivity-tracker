========================
GROQ SERVICE LAYER
========================

All communication with GROQ must be isolated in a dedicated service layer.

Do not call GROQ directly from routes, controllers, or frontend code.

Create:

/backend/services/groqService.js

Responsibilities:

- Receive requests from controllers
- Format and process existing application data for GROQ requests
- Preserve existing prompt engineering
- Send requests to GROQ
- Validate responses
- Handle retries
- Handle errors
- Measure response times
- Log requests and responses
- Return normalized responses

Flow:

Frontend
→ Controller
→ groqService
→ GROQ API
→ groqService
→ Controller
→ Frontend

Controllers must never contain GROQ business logic.
