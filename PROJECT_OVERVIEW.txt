# Productivity Tracker - Project Overview

## What is this?
A web app for competing with friends on productivity. Users sign in, complete tasks to earn XP, level up through ranks, and compare on a leaderboard. Data is stored in PostgreSQL via Supabase.

## Architecture
- **Frontend**: Vanilla JavaScript (ES modules), CSS, single-page app in `index.html`
- **Backend**: Node.js + Express
- **Database**: PostgreSQL through Supabase
- **Authentication**: bcrypt password hashing + JWT tokens
- **AI Integration**: GROQ API proxied through backend (never exposed to frontend)
- **Logging**: Structured Winston logging + persisted system logs
- **Serving**: Express serves static files from project root; app runs on port 3000

## Tech Stack
- **Frontend**: HTML, CSS, Vanilla JS (no framework)
- **Backend**: Node.js + Express
- **Database**: PostgreSQL (Supabase)
- **Auth**: bcrypt, JWT
- **AI**: GROQ API
- **Monitoring**: Winston structured logs, GROQ request/response logging

## Database Schema (PostgreSQL)

### users table
| Column | Type | Default | Description |
|--------|------|---------|-------------|
| id | UUID | gen_random_uuid() | Primary key |
| username | TEXT | - | Unique username (login ID) |
| password_hash | TEXT | - | bcrypt hash |
| xp | INTEGER | 0 | Total XP from xp_history |
| level | INTEGER | 0 | Current level (floor(xp/100)) |
| rank | TEXT | 'Newcomer' | Current rank name |
| language | TEXT | 'en' | UI language preference |
| avatar_url | TEXT | NULL | Supabase Storage public URL |
| goals | TEXT | '' | User's 5-year goals text |
| created_at | TIMESTAMPTZ | NOW() | Account creation time |
| updated_at | TIMESTAMPTZ | NOW() | Last update time |

### tasks table
| Column | Type | Default | Description |
|--------|------|---------|-------------|
| id | UUID | gen_random_uuid() | Primary key |
| user_id | UUID | - | Owner foreign key |
| task_text | TEXT | - | Task description |
| name | TEXT | - | Normalized task name |
| ai_score | INTEGER | 0 | AI rating score |
| xp_awarded | INTEGER | 0 | XP awarded for completion |
| completed | BOOLEAN | false | Completion state |
| duration | INTEGER | - | Duration in minutes |
| productivity | INTEGER | 0 | Productivity 0-5 |
| difficulty | INTEGER | 3 | Difficulty 1-5 |
| category | TEXT | 'other' | Task category |
| bonus | INTEGER | 0 | Offline bonus |
| created_at | TIMESTAMPTZ | NOW() | Creation time |
| completed_at | TIMESTAMPTZ | NULL | Completion time |

## API Routes

### Auth
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Current user profile

### Users
- `GET /api/users/:username` - Get user data (no password_hash)
- `PUT /api/users/:username` - Update user fields
- `POST /api/users/:username/password` - Change password
- `POST /api/users/:username/avatar` - Upload avatar
- `POST /api/users/:username/change-username` - Change username
- `GET/POST/DELETE /api/users/friends` - Friend management
- `GET /api/users/leaderboard` - Leaderboard

### Tasks
- `GET /api/tasks` - Get all tasks for current user
- `POST /api/tasks` - Create new task
- `PUT /api/tasks/:id` - Update task
- `DELETE /api/tasks/:id` - Delete task
- `POST /api/tasks/:id/complete` - Complete task (awards XP)

### Goals
- `GET /api/goals` - List goals
- `POST /api/goals` - Create goal
- `PUT /api/goals/:id` - Update goal
- `DELETE /api/goals/:id` - Delete goal

### XP & Leaderboard
- `GET /api/xp` - XP total and history
- `GET /api/leaderboard` - Leaderboard sorted by XP

### Settings
- `GET /api/settings` - User settings
- `PUT /api/settings` - Update settings

### AI
- `POST /api/groq/rate` - Rate a task with AI (Groq API proxy)
- `GET /api/groq/status` - AI service status
- `POST /api/ai/rate` (legacy) - AI task rating

## Key Business Logic

### XP Calculation
XP is calculated server-side when a task is created by the AI service and awarded/revoked immutably in `xp_history` on completion/uncompletion/deletion. `users.xp`, `users.level`, and `users.rank` are recalculated from `xp_history`.

### Rank Progression
- Newcomer: 0-99 XP
- Bronze: 100-299 XP
- Silver: 300-599 XP
- Gold: 600-1199 XP
- Platinum: 1200-2399 XP
- Diamond: 2400-4999 XP
- Master: 5000+ XP

Level = floor(totalXP / 100)

### Session Management
- JWT tokens stored in localStorage (remember me) or sessionStorage
- Frontend sends `Authorization: Bearer <token>` on protected requests
- Backend validates JWT on every protected route

### AI Task Rating
When a user describes a task, the backend sends the request to GROQ and returns standardized task data. Every request/response/error is logged in `groq_logs`. The GROQ API key only exists in backend environment variables.

## Important Notes for New Chat

1. **No Firebase anymore**: This version uses Express + PostgreSQL/Supabase. Firebase files were removed.
2. **Server required**: The app requires the Express server running (`node backend/index.js`).
3. **Supabase required**: A Supabase PostgreSQL project is required; SQLite is no longer used.
4. **Avatar storage**: Avatars are stored in Supabase Storage and returned as public URLs.
5. **Admin access**: Supabase Dashboard is the only administration interface. No admin routes or UI exist.
6. **Legacy routes**: `POST /api/ai/rate` and `GET /api/ai/status` are preserved for compatibility.
7. **Data migration**: `database/migrate-data.js` migrates SQLite data to PostgreSQL. Run it before deleting `data/app.db`.
8. **GROQ key security**: The GROQ API key is never exposed to the frontend.
9. **Server listens on `0.0.0.0`** for LAN access.
